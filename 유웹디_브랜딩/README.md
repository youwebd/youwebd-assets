# 유웹디_브랜딩

유웹디 브랜딩 자산(로고, 컬러, 서체, 프로필 사진, 브랜드 가이드 등)을 모아두는 폴더입니다.

- 주소 형식: https://cdn.jsdelivr.net/gh/youwebd/youwebd-assets@main/유웹디_브랜딩/파일명

## 견적서

- 견적서_작성_가이드.md: 견적서를 같은 디자인으로 다시 만드는 방법(필독)
- 견적서_생성기/: 견적 데이터(JSON)만 바꾸면 HTML·PDF·PPT(A4 2페이지)를 만드는 도구
- 샘플_하루건축_견적서.*: 기준 견적서(HTML·PDF·PPT)

## 마케팅 (인스타그램·스레드·네이버 블로그·당근마켓)

- 마케팅/: 채널별 홍보 결과물 폴더(영상, 캡션, 블로그 글, 당근 소식 등). 처음에 마케팅/README.md 를 보세요.
- 마케팅/공통/말해도_되는_사실과_규칙.md: 모든 채널 글이 따르는 사실·금지어·말투 기준
- 마케팅/채널별_저장.py: 영상에서 이미지를 뽑아 채널 폴더에 저장하고 모든 글을 검사
- 영상/: 영상 소스(릴스 reels.html, 브랜드 인트로)
