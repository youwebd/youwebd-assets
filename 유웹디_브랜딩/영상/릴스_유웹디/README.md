# 유웹디 릴스 — 대표님이 직접 운영하는 웹사이트

인스타그램 릴스용 모션그래픽 영상입니다. 9:16(1080x1920), 30fps, 36.1초, 무음(음악은 인스타그램 앱에서 추가).

| 파일 | 용도 |
|---|---|
| `유웹디_릴스_대표님이직접운영하는웹사이트_9x16.mp4` | 업로드용 영상 |
| `릴스_커버_2.48초.png` | 릴스 커버(3:4·4:5 미리보기에서도 핵심 문구가 잘리지 않음) |
| `게시글_캡션.txt` | 게시글 캡션과 해시태그 |
| `reels.html` | 영상 원본(시간 t를 넣으면 화면이 결정되는 애니메이션). 화면 문구는 이 파일에서 수정 |
| `prep_assets.py` | 사례 이미지·수정 시연 프레임 준비(원본은 수정하지 않음) |
| `render.js` | 프레임 캡처 → MP4 인코딩 |

## 구성 (목적 → 장면)

| 시간 | 장면 | 목적 |
|---|---|---|
| 0~3.2초 | 「오픈 뒤 문구 하나 바꾸는 데 며칠 기다리셨나요?」 + 요일이 쌓이는 메신저 | 훅 |
| 3.2~6.2초 | 데모 사이트 직접 수정 시연(문구 → 사진, 확대 렌즈) | 베네핏 증명 |
| 6.2~8.65초 | 유웹디는 1인 웹사이트 제작 스튜디오입니다 + 대표 사진 | 누가 |
| 8.65~12.2초 | 고치기 어려울 때 / 견적이 막막할 때 / 사이트가 없을 때 | 누구에게 |
| 12.2~14.75초 | 아임웹·식스샵 프로 반응형 홈페이지(고재가구소아) | 무엇을 |
| 14.75~17.8초 | 홈페이지는 계속 바뀝니다 → 문구·사진은 직접 고치도록 알려 드립니다 | 왜 |
| 17.8~20.2초 | **대표님이 직접 운영하는 웹사이트** | 슬로건 |
| 20.2~24.7초 | 오픈 뒤에도 혼자 두지 않습니다(1:1 운영 교육 / 만든 사람이 이어서 맡습니다 / 운영 매뉴얼) | 베네핏 |
| 24.7~32.8초 | 사례 5장: THEIC · UberHouse · 서경파츠(고객사) / A-LINE STUDIO · LUXENOVA(데모 표기) | 제작 사례 |
| 32.8~36.1초 | 슬로건 + 「유웹디 카카오톡 채널에 / 상담 원해요 / 한마디면 시작합니다.」 | 행동 유도 |

근거: 2026년 9월 홈페이지 리뉴얼 메시지(youwebd.co.kr, 네이버 블로그 2026-09-28), Notion 릴스 톤 규칙(금지어·성과 단정 금지). 가격 숫자는 넣지 않았습니다.

## 다시 만들기

```bash
cd 유웹디_브랜딩/영상/릴스_유웹디
python3 prep_assets.py                 # 자산 준비 (Pillow, ffmpeg 필요)
npm install playwright                 # 최초 1회 (크롬: npx playwright install chromium 또는 CHROME_PATH)
node render.js                         # → 유웹디_릴스_대표님이직접운영하는웹사이트_9x16.mp4
```

글꼴은 `../../견적서_생성기/fonts/` 의 Pretendard 서브셋을 씁니다.

## 업로드 전 확인

- 고객사 4곳(고재가구소아·THEIC·UberHouse·서경파츠)의 인스타그램 게시 동의 (Notion '공개 동의 범위'가 비어 있음)
- 대표 사진 사용, 카카오톡 채널 검색 이름이 '유웹디'인지
- 수정 시연은 데모 사이트의 편집 화면입니다(화면에 '데모 사이트 수정 예시', 캡션에도 명시)
