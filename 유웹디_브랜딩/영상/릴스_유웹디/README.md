# 유웹디 릴스 — 대표님이 직접 운영하는 웹사이트

인스타그램 릴스용 모션그래픽 영상입니다. 9:16(1080x1920), 30fps, 36.5초, 무음(음악은 인스타그램 앱에서 추가).

| 파일 | 용도 |
|---|---|
| `유웹디_릴스_대표님이직접운영하는웹사이트_9x16.mp4` | 업로드용 영상 |
| `릴스_커버_2.48초.png` | 릴스 커버(3:4·4:5 미리보기에서도 핵심 문구가 잘리지 않음) |
| `게시글_캡션.txt` | 게시글 캡션과 해시태그 |
| `reels.html` | 영상 원본(시간 t를 넣으면 화면이 결정되는 애니메이션). 화면 문구는 이 파일에서 수정 |
| `prep_assets.py` | 사례 이미지·수정 시연 프레임 준비(원본은 수정하지 않음) |
| `render.js` | 프레임 캡처 → MP4 인코딩 |

## 구성 (목적 → 장면)

| 시간 | 장면 | 목적 |
|---|---|---|
| 0~3.6초 | 「홈페이지 문구 하나 / 업체에 맡기고 / 며칠 기다리셨나요?」 + 「홈페이지 제작업체」 대화창: 홈페이지 영업시간 10:00 – 20:00에 빨간 동그라미 → 11:00 – 21:00, 「이 부분만 바꿔 주세요」(읽지 않음 1) + 「답장 기다린 지 1일째 → 3일째」 | 훅 |
| 3.6~6.6초 | 이제 대표님이 직접 바꿉니다 — 직접 수정 시연(문구 → 사진, 확대 렌즈, 「바로 반영」, 라벨 「수정 예시」) | 베네핏 증명 |
| 6.6~9.05초 | 유웹디는 1인 웹사이트 제작 스튜디오입니다 + 고객사 신공간디자인연구소 사이트 메인 → 스크롤 | 누가 |
| 9.05~12.6초 | 고치기 어려울 때 / 견적이 막막할 때 / 사이트가 없을 때 | 누구에게 |
| 12.6~15.15초 | 아임웹·식스샵 프로 반응형 홈페이지(서경파츠 PC·모바일) | 무엇을 |
| 15.15~18.2초 | 홈페이지는 계속 바뀝니다 → 문구·사진은 직접 고치도록 알려 드립니다 | 왜 |
| 18.2~20.6초 | **대표님이 직접 운영하는 웹사이트** | 슬로건 |
| 20.6~25.1초 | 오픈 뒤에도 혼자 두지 않습니다(1:1 운영 교육 / 만든 사람이 이어서 맡습니다 / 운영 매뉴얼) | 베네핏 |
| 25.1~33.2초 | 「유웹디가 만든 고객사 홈페이지」 사례 5장: 기업 THEIC · 쇼핑몰 고재가구소아 · 스튜디오 셔터플레이 · 아카데미 MBC 모델센터 · 건축·인테리어 우버하우스 | 제작 사례 |
| 33.2~36.5초 | 슬로건 + 「유웹디 카카오톡 채널에 / 상담 원해요 / 한마디면 시작합니다.」 | 행동 유도 |

근거: 2026년 9월 홈페이지 리뉴얼 메시지(youwebd.co.kr, 네이버 블로그 2026-09-28), Notion 릴스 톤 규칙(금지어·성과 단정 금지). 가격 숫자는 넣지 않았습니다.
제작 실적은 개수(예: 「열 곳 넘게」)로 말하지 않고, 화면에 실제 고객사 사이트를 보여 주며 「유웹디가 만든 고객사 홈페이지」라고만 씁니다. 정확한 누적 제작 건수를 확인하면 그 숫자로 바꿀 수 있습니다.

## 다시 만들기

```bash
cd 유웹디_브랜딩/영상/릴스_유웹디
python3 prep_assets.py                 # 자산 준비 (Pillow, ffmpeg 필요)
npm install playwright                 # 최초 1회 (크롬: npx playwright install chromium 또는 CHROME_PATH)
node render.js                         # → 유웹디_릴스_대표님이직접운영하는웹사이트_9x16.mp4
```

글꼴은 `../../견적서_생성기/fonts/` 의 Pretendard 서브셋을 씁니다.

## 업로드 전 확인

- 고객사 7곳(THEIC·고재가구소아·셔터플레이·MBC 모델센터·우버하우스·신공간디자인연구소·서경파츠)은 사전 계약 시 게시 동의를 받았습니다.
- 카카오톡 채널 검색 이름이 '유웹디'인지
- 수정 시연은 예시 화면입니다(화면 라벨 「수정 예시」, 캡션에도 명시)
