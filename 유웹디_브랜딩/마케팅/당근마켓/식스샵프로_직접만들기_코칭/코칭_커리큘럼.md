# 직접 만들기 코칭 — 커리큘럼 초안

상태: **초안, 유웹디 대표님 확인 전.** 아직 어디에도 올리거나 안내하지 않았어요.
서비스 이름 「직접 만들기 코칭」은 이 초안에서 임시로 붙인 이름이에요. 쓰실 이름을 정해 주세요.

## 읽는 법

- 이 문서에서 「대표님」은 두 분을 가리켜요. 소개와 주제 설명의 「대표님」은 코칭을 받는 분이고, 위의 상태 줄과 맨 아래 「대표님이 정해 주세요」의 「대표님」은 유웹디 대표님이에요.
- **[확정]** 은 유웹디 대표님이 알려 주신 사실이에요. **[확인 필요]** 는 원문을 제가 풀어 읽었거나 공식 자료로 확인하지 못해서 확인이 필요한 내용이에요. **(제안)** 은 이 초안이 제안하는 내용이라 확정이 아니에요. 제안은 고르거나 고치거나 빼 주세요. 「이런 대표님께」와 「함께 해 보는 것」 아래 항목은 모두 제안이에요.
- 코칭 시간·회차·기간에 대한 숫자는 정하지 않았어요. 요금(3만원, 기존 5만원)과 첫 1시간 무료만 썼고, 주제·순서 번호는 구분용이에요.
- 이 초안은 코칭 결과나 성과를 미리 약속하는 말을 쓰지 않았고, 공식 자료로 확인하지 못한 식스샵 프로 기능은 단정해서 설명하지 않았어요.
- 사실 기준: `마케팅/공통/말해도_되는_사실과_규칙.md` 의 「코칭 서비스 사실」.

## 주제 1. 식스샵 프로 AI 활용

**이런 대표님께 (제안)**

- 식스샵 프로로 웹사이트를 직접 만들고 있거나 만들려는 대표님
- 만드는 과정에 AI를 쓰고 싶은데 어디서부터 정해야 할지 막막한 대표님
- AI에게 무엇을 어떻게 물어야 할지 모르겠는 대표님

**함께 해 보는 것 (제안)**

- 대표님 사이트에서 AI에게 부탁해 보고 싶은 일이 무엇인지 같이 정리해 봐요
- 정리한 일을 대표님이 직접 AI에 부탁해 보고, 결과를 같이 살펴봐요
- 마음에 들지 않는 부분은 부탁하는 말을 바꿔 다시 해 봐요
- AI가 내놓은 답을 그대로 쓰지 않고, 대표님이 확인하는 순서를 같이 정해 봐요
- 이번에 해 본 순서를 대표님이 직접 메모해 둬요

**준비해 오실 것** (노트북 외에는 제안)

- 노트북 (필수) [확정]
- 만들고 있거나 만들려는 사이트의 주제나 이름
- 식스샵 프로에 접속할 수 있는 계정
- 써 보고 싶은 AI 도구가 있다면 그 이름

[확인 필요] 「식스샵 프로 AI 활용」이 식스샵 프로 안의 기능을 뜻하는지, 별도의 AI 도구를 함께 쓰는 것인지는 공식 자료로 확인하지 못했어요. 그래서 위 항목은 AI를 쓰는 일반적인 방식으로만 적었고, 식스샵 프로 기능의 세부는 쓰지 않았어요.

## 주제 2. MCP 연결

[확인 필요] 일반 용어 풀이: MCP는 AI 도구를 다른 도구·서비스와 이어 주는 연결 방식을 가리키는 말이에요. 식스샵 프로와 어떻게 이어지는지는 공식 자료로 확인하지 못해 쓰지 않았어요. 소식·광고·카드에는 풀이 없이 「MCP 연결」이라고만 썼어요.

**이런 대표님께 (제안)**

- 「MCP 연결」이라는 말은 들었는데 내 작업에서 무엇을 연결하는 일인지 막막한 대표님
- 연결을 해 보려다 중간에 막힌 대표님

**함께 해 보는 것 (제안)**

- 대표님이 어떤 도구나 서비스를 AI와 연결하고 싶은지 먼저 이야기해 봐요
- 연결에 필요한 것과 순서를 같이 확인하고, 대표님이 직접 따라 해 봐요
- 막히는 곳이 어디인지 짚어 보고 다시 해 봐요
- 연결한 뒤 대표님이 직접 써 보며 잘 이어졌는지 살펴봐요

**준비해 오실 것** (노트북 외에는 제안)

- 노트북 (필수) [확정]
- 연결해 보고 싶은 AI 도구와 서비스의 이름
- 각 서비스에 로그인할 수 있는 계정. 로그인은 대표님이 직접 해요 (로그인 정보 취급은 맨 아래 표에서 정해 주세요)
- 막혔을 때 나온 화면이나 메시지가 있으면 캡처해 오세요

## 주제 3. 블록 세팅 설정

[확인 필요] 「블록 세팅 설정」은 유웹디 대표님이 쓰신 말 그대로예요. 식스샵 프로 화면에서 어떤 항목을 가리키는지는 공식 자료로 확인하지 못해서 풀이를 쓰지 않았어요.

**이런 대표님께 (제안)**

- 식스샵 프로로 사이트를 만들다가 블록 세팅 설정에서 막히는 대표님
- 어떤 설정부터 건드려야 할지 순서를 정하지 못한 대표님
- 아직 사이트를 만들기 전이어서 어떤 설정이 필요한지 알고 싶은 대표님

**함께 해 보는 것 (제안)**

- 대표님이 만들고 있는 페이지를 열어 두고, 막히는 설정이 무엇인지 하나씩 짚어 봐요
- 설정 하나를 대표님이 직접 바꿔 보고, 바뀐 결과를 같이 살펴봐요
- 바꿀 설정의 순서를 같이 정해 봐요
- 이번에 해 본 설정 순서를 대표님이 직접 메모해 둬요

**준비해 오실 것** (노트북 외에는 제안)

- 노트북 (필수) [확정]
- 만들고 있는 사이트가 있다면 접속할 수 있는 상태, 아직 없다면 만들고 싶은 사이트에 대한 메모
- 막히는 부분을 적은 메모나 화면 캡처

## 하지 않는 일

- 이 코칭에서는 유웹디가 대표님의 웹사이트를 대신 만들어 드리지 않아요. 대표님이 직접 만드시는 것을 옆에서 코칭하는 서비스예요. [확정]
- 대표님 계정에 대신 로그인해서 작업하지 않아요. 로그인은 대표님이 직접 해요. (제안)
- 대신 만들어 달라는 문의는 제작 상담으로 나누고, 코칭과 섞어 안내하지 않아요. 구분할 말은 아래 표에서 정해 주세요. (제안)
