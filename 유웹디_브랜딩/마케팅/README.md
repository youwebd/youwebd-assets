# 유웹디 마케팅

홍보 채널별 결과물을 **채널 → 캠페인(또는 글) 폴더** 순서로 모아 둔 곳입니다. 올릴 파일은 모두 여기서 찾으면 됩니다.

```text
마케팅/
├─ 공통/말해도_되는_사실과_규칙.md        ← 모든 채널 글의 사실·금지어·말투 기준 (새 글 쓰기 전에 먼저 읽기)
├─ 채널별_저장.py                          ← 영상에서 이미지 뽑기 + 모든 채널 글 검사 (아래 사용법)
├─ 인스타그램/릴스_대표님이직접운영하는웹사이트/
│    ├─ 유웹디_릴스_…_9x16.mp4   (40초, 1080x1920, 무음)
│    ├─ 릴스_커버_5.28초.png
│    └─ 게시글_캡션.txt
├─ 스레드/릴스_대표님이직접운영하는웹사이트/스레드_게시글.txt   (반말체, 6개 연결 글 + 한 편 버전)
├─ 네이버블로그/소상공인홈페이지제작_업체고를때확인할점/
│    ├─ 네이버블로그_게시글.md        (발행 정보 · 이미지 순서 · 본문)
│    ├─ 네이버블로그_붙여넣기용.txt   (편집기에 붙여넣기용)
│    ├─ 네이버_임시보관함_자동저장.md  (임시보관함 자동 저장 방법과 현재 상태)
│    └─ 이미지/ IMG-01~16
└─ 당근마켓/
     ├─ 동네사장님_홈페이지문구수정/   (제작 후 운영 교육)
     │    ├─ 당근마켓_소식_광고문구.md   (소식 2편 · 광고 문구 3개 · 올리기 전에 확인할 것)
     │    ├─ 당근마켓_붙여넣기용.txt
     │    └─ 이미지/
     └─ 식스샵프로_직접만들기_코칭/    (대표님이 직접 만들도록 코칭, 지역 한정)
          ├─ 당근마켓_소식_광고문구.md   (소식 2편 · 광고 문구 4개 · 올리기 전에 확인할 것)
          ├─ 당근마켓_붙여넣기용.txt
          ├─ 코칭_커리큘럼.md            (초안: [확정]·[확인 필요]·(제안) 구분, 대표님이 정해 주세요 표)
          ├─ 이미지/ CARD-01~03        (1080x1080)
          └─ 이미지_소스/ cards.json, render_cards.js   (NODE_PATH=/opt/node22/lib/node_modules node render_cards.js)
```

영상을 만드는 소스는 `../영상/릴스_유웹디/`(reels.html·render.js 등)에 있고, 렌더하면 결과 mp4가 위 인스타그램 폴더에 바로 저장됩니다.

## 자동 저장·검사

```bash
cd 유웹디_브랜딩/마케팅
python3 채널별_저장.py            # 블로그·당근 이미지를 영상에서 다시 뽑고, 모든 채널 글을 검사
python3 채널별_저장.py --render   # 영상·커버부터 다시 렌더한 뒤 위 작업 (node, playwright, ffmpeg 필요)
python3 채널별_저장.py --check    # 검사만
```

검사 항목: 금지어·미검증 표현, 인스타그램 캡션 2,200자·해시태그 30개, 스레드 글마다 500자·주제 태그 1개, 블로그 제목 100자·태그 30개(공백 없이)·본문 이미지 파일 존재, 영상 1080x1920과 길이, 당근 소식 500자·광고 제목 20자·본문 60자(캠페인 폴더마다). 코칭 캠페인은 「무료」가 있으면 같은 글에 「3만원」, 「경기 광주」가 있으면 「신현동·능평동」도 있는지 확인합니다.

## 채널별로 올리는 방법

| 채널 | 방법 |
|---|---|
| 인스타그램 | 앱에서 릴스에 mp4를 올리고 커버·캡션을 붙입니다. 음악은 앱에서 고릅니다. |
| 스레드 | 1번 글에 영상을 붙이고 2~6번은 이어 쓰는 글로 올립니다. 한 편으로 올리려면 아래 「한 편 버전」을 씁니다. |
| 네이버 블로그 | `네이버_임시보관함_자동저장.md` 참고. Claude가 임시보관함에 자동 저장하고, 발행은 직접 합니다(크롬 확장이 켜져 있어야 함). |
| 당근마켓 | 비즈프로필 「소식」에 본문과 사진을 올립니다. 올리기 전 확인할 것은 글 파일 맨 아래에 있습니다. |

## 새 글·새 채널 추가

1. `공통/말해도_되는_사실과_규칙.md` 를 읽고 그 안의 사실만 씁니다.
2. `마케팅/<채널>/<캠페인 또는 글 이름>/` 에 저장합니다. 새 채널이면 위 구조도와 공통 문서의 채널 표에 한 줄을 추가합니다.
3. `python3 채널별_저장.py --check` 로 검사합니다.
