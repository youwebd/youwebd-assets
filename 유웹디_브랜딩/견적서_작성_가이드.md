# 유웹디 견적서 작성 가이드

하루건축 샘플 견적서를 기준으로, **다른 고객의 견적서도 똑같은 디자인·구성으로** 만들기 위한 가이드입니다.
견적 항목과 고객 정보만 JSON으로 바꾸면 **HTML · PDF(A4 2페이지) · PPT(A4 2슬라이드)** 가 한 번에 나옵니다.

- 기준 견적서: `샘플_하루건축_견적서.html / .pdf / _A4.pptx`
- 생성기: `견적서_생성기/` (이 가이드와 같은 폴더 안)
- 디자인은 하루건축 샘플과 **픽셀 단위로 동일**하게 검증되어 있습니다.

---

## 1. 빠른 사용법

```bash
cd 유웹디_브랜딩/견적서_생성기
npm install                                   # 최초 1회 (pptxgenjs, playwright)
npx playwright install chromium               # 최초 1회 (크롬이 이미 있으면 생략, CHROME_PATH 지정 가능)

cp 하루건축.json 새고객.json                   # 견적 데이터 복사 후 수정
python3 build.py 새고객.json                   # → output/견적서_새고객.html
node export.js output/견적서_새고객.html       # → output/견적서_새고객.pdf, 견적서_새고객_A4.pptx
```

- `build.py` 는 파이썬 기본 라이브러리만 사용합니다(추가 설치 없음).
- `export.js` 는 페이지 내용이 푸터를 침범하면 **경고**를 출력합니다(종료 코드 2). 경고가 나오면 항목·문구를 줄이세요.
- 결과는 `output/` 에 생기며 git 에는 올라가지 않습니다(`.gitignore`).

## 2. 견적 데이터(JSON) 작성

고객마다 바뀌는 값만 `새고객.json` 에 적습니다. 나머지(유웹디 정보, 계좌, 호스팅 요금, 비고)는 `기본값.json` 이 채웁니다.

```json
{
  "sample": false,
  "quoteNo": "YWD-20261008-002",
  "client": { "name": "온담건설", "project": "온담건설 홈페이지 제작" },
  "date": "2026년 10월 9일",
  "items": [
    { "title": "기획 및 사이트 구조 설계", "sub": "메뉴 구성, 페이지 흐름", "qty": "1식", "amount": 500000 }
  ]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `sample` | 선택 | `true` 면 `SAMPLE` 배지와 "본 문서는 샘플입니다" 문구 표시. 실제 견적서는 `false`(또는 생략) |
| `quoteNo` | 선택 | 견적번호. 생략하면 `YWD-오늘날짜-001`. 샘플 JSON 을 복사했다면 반드시 변경 |
| `client.name` | 필수 | 수신 상호. 파일 이름에도 쓰임(`견적서_○○.html`) |
| `client.project` | 필수 | 프로젝트명 |
| `date` | 필수 | 견적일. 쓴 그대로 표시(예: `2026년 10월 9일`) |
| `validity` | 선택 | 유효기간. 기본 "견적일로부터 14일" |
| `subtitle` | 선택 | 제목 아래 문구. 기본 "홈페이지 제작 견적" |
| `items[]` | 필수 | **1~6개**. `title`, `sub`(설명 한 줄), `qty`(기본 `1식`), `amount`(**숫자**, 공급가액, 쉼표 없이) |
| `hosting` | 선택 | `false` 면 "별도 결제 비용 안내" 박스를 뺍니다. 요금을 바꾸려면 객체로 덮어쓰기 |
| `account` | 선택 | `false` 면 입금 계좌 박스를 뺍니다 |
| `notes[]` | 선택 | 비고를 통째로 교체. `{total}` `{supply}` `{vat}` 로 금액 자동 삽입, `<strong>` 사용 가능 |
| `supplier` | 선택 | 공급자 정보를 이 견적서만 다르게 할 때 |

### 계산 규칙 (자동)

- 공급가액 = `items[].amount` 의 합계
- 부가세 = 공급가액 × 10% (원 단위 반올림). **금액은 항상 부가세 별도로 입력**합니다.
- 합계 = 공급가액 + 부가세. 총액 박스·합계 줄·비고의 `{total}` 이 모두 같은 값으로 채워집니다.

### 고정 정보 바꾸기 → `기본값.json`

사업자번호, 대표, 이메일, 입금 계좌, 아임웹·식스샵 요금, 도메인·SSL 비용, 기본 비고(결제 조건·제작 기간·수정 횟수)는 `기본값.json` 한 곳에서 관리합니다.
요금이 바뀌면 이 파일만 고치면 이후 모든 견적서에 반영됩니다.

## 3. 페이지 구성 (A4 세로, 2페이지)

| 페이지 | 구성 (위 → 아래) |
|---|---|
| **1페이지** | 로고·상호 → `견 적 서` 제목 → 견적번호 → **수신 / 공급자** 박스 → **총 견적금액 박스**(빨강) → **항목 표** → 공급가액·부가세·**합계** |
| **2페이지** | 로고·견적번호 → **별도 결제 비용 안내**(아임웹 Starter/Pro, 식스샵 프로 홈페이지/쇼핑몰 체크박스 → 공통 비용: 도메인·SSL) → **입금 계좌** → **비고** |
| 공통 | 우측 상단 `SAMPLE`(샘플일 때), 하단 푸터(`유웹디 · 이메일` / `n / 2`) |

- 체크박스는 인쇄 후 펜으로 표시하는 용도입니다(HTML 화면에서는 클릭 가능).
- 항목이 6개일 때는 표 간격이 자동으로 조금 좁아집니다. **7개 이상은 지원하지 않습니다**(1페이지를 넘침) — 항목을 묶으세요.

## 4. 디자인 규격 (변경 금지)

디자인의 원본은 `견적서_생성기/template.css` 입니다. 주요 값은 다음과 같습니다.

**색상**

| 이름 | 값 | 용도 |
|---|---|---|
| accent | `#c82828` | 제목, 총액 박스, 표 머리글 글자·상단선, 카드 헤더 글자 (유웹디 로고 빨강) |
| accent-soft | `#fbeeee` | 표 머리글·카드 헤더 배경 |
| ink | `#16181d` | 본문 글자, 합계 위 굵은 선 |
| sub | `#5b6270` | 보조 글자(라벨, 설명, 푸터) |
| line | `#e3e6ec` | 박스·표 구분선 |
| 공통 비용 헤더 | `#f6f7f9` | "공통 비용"·"입금 계좌" 헤더 배경 |

**글꼴: Pretendard** (HTML·PDF 에 내장되어 있어 설치 불필요)

| 요소 | 크기 · 굵기 |
|---|---|
| 제목 `견 적 서` | 34px · 700 · 자간 0.3em · accent |
| 총액 숫자 | 28px · 700 |
| 합계(큰 줄) | 16px · 700 |
| 항목 표 본문 / 설명 | 13.5px / 12px (설명은 sub 색) |
| 박스 라벨·값 | 13.5px |
| 박스 제목(수신·공급자) | 12px · 600 · 자간 0.1em |
| 호스팅 안내 제목 | 15px · 700 |
| 비고 | 12.5px · 제목 12px |
| 푸터 | 12px |

**치수**: 용지 210×297mm, 여백 상 16mm · 좌우 18mm · 하 24mm, 박스 모서리 10px, 박스 사이 16px, 섹션 사이 26~28px.

## 5. 출력물과 사용처

| 파일 | 용도 |
|---|---|
| `견적서_○○.pdf` | **인쇄·발송용.** A4 2페이지, 글꼴 내장 |
| `견적서_○○.html` | 브라우저로 열기. 우측 하단 **인쇄 / PDF 저장** 버튼 또는 Ctrl+P (용지 A4, 여백 없음, 배경 그래픽 켜기, 배율 100%) |
| `견적서_○○_A4.pptx` | PowerPoint 에서 수정. 표·도형·텍스트가 개별 개체. **Pretendard 폰트를 먼저 설치**해야 모양이 같습니다 → https://github.com/orioncactus/pretendard |

PPT 는 글자가 줄 단위 텍스트 상자로 나뉘어 있어서, 문구를 고치면 해당 줄만 수정하면 됩니다.

## 6. 작성 후 검수 체크리스트

1. `export.js` 가 경고 없이 끝났는가 (푸터 침범 없음)
2. PDF 가 정확히 **2페이지**이고 용지가 A4 인가 (`pdfinfo 파일.pdf`)
3. 총액 = 공급가액 + 부가세, 항목 합계와 일치하는가
4. 고객 상호·프로젝트명·견적일·견적번호에 오타가 없는가, 이전 고객 이름이 남아 있지 않은가
5. 실제 견적서는 `"sample": false` 로 해서 `SAMPLE` 배지가 없는가, **견적번호에 `SAMPLE` 이 남아 있지 않은가** (하루건축.json 을 복사했다면 `quoteNo` 를 꼭 바꾸세요)
6. 입금 계좌·사업자번호가 최신인가 (`기본값.json`)
7. PDF 를 이미지로 변환해 1·2페이지를 눈으로 확인했는가

## 7. Claude 에게 요청하는 방법

새 견적서가 필요할 때 아래 형식으로 요청하면, 이 가이드와 생성기를 그대로 사용해 같은 디자인으로 만듭니다.

```text
견적서_작성_가이드.md 대로 견적서 만들어줘.
- 고객: ○○○  / 프로젝트: ○○○ 홈페이지 제작
- 견적일: 2026년 ○월 ○일
- 항목(부가세 별도): 
  1. 기획 및 구조 설계 400,000
  2. UI/UX 디자인 1,000,000
  3. ...
- 샘플 아님 (실제 발송용)
- 호스팅 비용 안내: 포함 / 제외
```

Claude 가 따르는 순서: ① `견적서_생성기/○○.json` 작성 → ② `build.py` → ③ `export.js` → ④ PDF 를 이미지로 확인(체크리스트) → ⑤ HTML·PDF·PPT 를 전달.
가이드에 없는 디자인 변경(색, 글꼴 크기, 배치)은 **요청받았을 때만** `template.css` 를 수정하고, 하루건축 샘플이 그대로 나오는지 다시 확인합니다.

## 8. 폴더 구성

```text
유웹디_브랜딩/
├─ 견적서_작성_가이드.md        ← 이 문서
├─ youwebd-logo.png             ← 견적서에 들어가는 로고
├─ 샘플_하루건축_견적서.html / .pdf / _A4.pptx   ← 기준 견적서
└─ 견적서_생성기/
   ├─ 기본값.json               ← 유웹디 정보·계좌·호스팅 요금·기본 비고
   ├─ 하루건축.json             ← 견적 데이터 예시 (복사해서 사용)
   ├─ build.py                  ← JSON → HTML
   ├─ export.js                 ← HTML → PDF + PPTX
   ├─ template.css              ← 디자인 원본
   ├─ fonts/                    ← Pretendard 400·600·700 (한글 KS X 1001 + 영문·숫자 서브셋)
   └─ package.json
```

> **글꼴 범위**: 내장 폰트는 자주 쓰는 한글 2,350자 + 영문·숫자·기호입니다. 드문 한글(예: 일부 고객 이름)은 시스템 글꼴로 대체되어 모양이 조금 다를 수 있습니다.
